# 別被雷劈到 · ¡Cuidado con el rayo!

中文讀音打字遊戲（給西語學生）。看到一個字，在時間內用內建的拼音或注音鍵盤打出讀音（要打聲調）。
打對往上走一階；打錯或時間到，被雷劈一次，但還是往上走。爬完 10 階，看被劈幾次。

- 網址：https://wangchiapin.github.io/Cuidado-con-el-rayo/
- 單檔 `index.html`，直接用 GitHub Pages 開（Settings → Pages → main / root）。
- 介面可切換：繁體／簡體、中文／西文／英文。拼音鍵盤、注音鍵盤都有（電腦也能直接用實體鍵盤打）。
- 首頁很簡單：人物、標題、一顆顯示目前「難度 · 鍵盤 · 暱稱」的膠囊，底下是 開始／👥 連線／🏆 排行榜。**右上角 ⚙ 是設定**（角色、字形、介面語言、鍵盤、難度、暱稱，全部在裡面），**❓ 是遊戲說明**，旁邊是 🔊 靜音。人物每次回首頁、每次再玩都會隨機換一個（男生或女生在設定裡選）。

## 難度

三種難度，差別在「題庫範圍」和「每題時間」。字的等級用「華語八千詞」：N1、N2 = 準備級，L1 入門、L2 基礎、L3 進階、L4 高階、L5 流利（數字越大越難）。

| 難度 | 每題時間 | 字的範圍 | 字數 |
|---|---|---|---|
| 簡單 | 15 秒 | N1、N2、L1 | 355 |
| 普通 | 10 秒 | N2、L1、L2、L3 | 598 |
| 進階 | 10 秒 | L2、L3、L4、L5，加上輕聲字（的、嗎、吧…） | 1,021 |

輕聲字只在進階出現。一局固定 10 階，每階一個字。星星：沒被劈 3 顆，被劈 1～2 次 2 顆，3～5 次 1 顆，6 次以上 0 顆。

## 排行榜（Firebase）

- 開始畫面可以輸入暱稱（最多 14 個字，存在自己的手機裡）；🏆 鈕看排行榜。
- **簡單、普通、進階各一個榜**，拼音和注音玩家在同一個榜（鍵盤只是輸入方式，題目一樣難）。
- 排名：**被雷劈越少越前面，一樣就比誰爬得快**。只顯示前 10 名，自己那一列會標色。
- 每台裝置（匿名登入）每個難度只留一筆最好成績；比較差的成績不會蓋掉好的。
- 沒有暱稱時，結算畫面會先給你看榜，再問暱稱，輸入後才上榜。
- 讀不到榜單時，遊戲照常玩，只是榜單區顯示「暫時無法使用」。
- Firebase 專案：`memorma-24dab`（跟翻牌記憶、收納小達人等同一個）。
- 資料位置：`rayo_boards/{easy|normal|hard}/entries/{匿名登入的 uid}`
  - 欄位：`name`、`strikes`（被劈次數 0～10）、`secs`（用時秒數）、`kb`（`pinyin`／`zhuyin`）、`rank`、`updatedAt`
  - `rank = (10 − 被劈次數) × 100000 + (99999 − 用時秒數)`，越大越前面。
- **安全規則**：完整版在 `firestore.rules.txt`（是 memorma 現行規則加上這個遊戲的 `rayo_boards`（排行榜）和 `rayo_rooms`（連線房間）兩個區塊，其他一個字都沒動）。要上線時，把整份貼到 Firebase 主控台 → Firestore → 規則 → 發布。也請把同一份蓋到 Memorama repo 的 `firestore-rules-full.txt`，才不會下次改規則時把這一段弄丟。

## 連線模式（最多 15 人，一條命）

首頁按 👥「連線」。**誰都可以開房**，房主選難度，其他人輸入 4 位數房號（或點邀請連結 `?room=房號`）加入。

- 全部人**同一題、同時作答、同時揭曉**：每個人用自己選的鍵盤（拼音／注音）打；打完只會顯示「已送出，等其他人」，等全部人答完（或時間到）才一起揭曉。
- **一條命**：打錯或時間到，就被雷劈、出局。**有幾個人出局，就落幾道雷**，各自打在那個人身上（小人變黑、眼睛變叉）。
- 出局的人可以**留下來觀賽**；也可以在加入時勾「我只觀賽」。比賽開始後才進來的人，一律觀賽。
- 街上同時有多個小人一起爬，每個人頭上有名字（人多時只顯示前 3～4 個字，完整名字在下方名字列）；自己的小人標紅色。
- 沒人出局的人每題往上一階；爬完 10 階還活著的人**並列登頂**。全部人同一題出局，就並列第一、直接結束。名次＝撐到第幾階，同階並列。
- 成績**不進排行榜**，只有每一局結束時那張名次表。房主可以按「再來一局」（換新的 10 題）。
- 最少 2 位玩家才能開始；房主離開＝關閉整間房；房間 6 小時後自動失效；房主斷線時，其他人約 30 秒後會看到提示，可以自己離開。
- 遊玩紀錄：連線的局數記成 `room-難度-鍵盤`（例如 `room-normal-pinyin`），後台「遊玩紀錄」分頁看得到。

做法（給之後改程式的人）：房主那台負責推進回合，其他人只寫自己的答題結果，所以不需要另外的伺服器。
- `rayo_rooms/{房號}`：房主寫（難度、題目 `qs`、參賽名單 `ro`、第幾題 `rd`、階段 `ph`＝ready／ask／reveal／end、出局表 `elim`、結果 `final`、局數 `n`）。
- `rayo_rooms/{房號}/players/{uid}`：每個人只寫自己的（暱稱、角色、是否觀賽、答題結果 `a`：第幾題 → 1 對／0 錯）。
- 時間到沒送出，或離線沒答，一律算答錯。
- 限制：這是朋友／班上用的房間，答題結果由各人的手機自己回報，規則只檢查格式、不檢查答案是否真的打對；15 人上限由程式檢查（規則沒辦法數人數）。

## 遊玩紀錄

跟所有遊戲一樣用 game-kit 的 `plays.js`，遊戲代號 `rayo`，寫到 memorma 專案：

- `visits`：打開頁面時記一次（每台裝置每天一筆）。
- `plays`：按「開始」記一局，爬完 10 階時補上結果（`level` 例如 `normal-pinyin`、`score` = 答對題數、`secs`、暱稱）；中途離開的那一局就是「沒玩完」。
- 後台（分享區 stats.html）的「遊玩紀錄」分頁和「排行榜總覽」都看得到。

## 字庫從哪裡來

不另外維護字庫，全部取自 game-kit（你的共用零件 repo）：

- 華語八千詞等級（`bank/vocab_levels.json`）→ 只取單字；
- GoodTeacher 台灣讀音表（`bank/gt/readings.txt`）→ 台灣讀音，多音字只收基本讀音和規則會改成的讀音；
- 沒收錄的單音字用 `pinyin-pro` 補，簡體字用 `opencc-js` 轉。

要改字庫，請改 game-kit 的資料，再重新執行下面的「重新產生」。

## 重新產生（改了程式或字庫才需要）

`index.html` 是自動組出來的：`src/template.html`（遊戲本體）＋ game-kit 的共用零件（靜音鍵、版權小字、遊玩紀錄等）＋ 字庫 ＋ 程式畫的人物和街景（背景一共 7 個台灣場景：九份（`tools/world.js`）＋ 象山看台北 101、中正紀念堂、龍山寺、阿里山檜木棧道、猴硐貓村、夜市天橋（`tools/scenes/*.js`，共用的小工具在 `lib.js`）。除了夜市之外，圖上都不放文字。每一局隨機換（連兩局不會一樣）；連線時由「房號＋第幾局」算出同一個背景，所以全房間看到的一樣，不需要多存任何資料）。所以重新組檔時，需要電腦上有 **game-kit 資料夾**（預設放在 `/home/claude/game-kit`，放別處就用 `GAMEKIT=資料夾路徑` 告訴它）。平常只是玩遊戲、或只改 `index.html` 以外的說明文字，完全用不到。

```
npm install
node tools/build_words.js   # 產生 data/words.json（讀 game-kit 的字庫）
node tools/build.js         # 產生 index.html（改了 src/template.html 一定要跑）
python3 tests/test_game.py          # 遊戲自動測試（Playwright + Chromium）
python3 tests/test_leaderboard.py   # 排行榜＋遊玩紀錄測試（假的 Firebase，不連網）
python3 tests/test_multi.py         # 連線模式測試（多個瀏覽器分頁＋假資料庫＋規則的 Python 版，約 3 分鐘）
```
